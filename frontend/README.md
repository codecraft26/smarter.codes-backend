# Frontend (Next.js)

## Setup
1. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```
2. Create a `.env.local` file:
   ```env
   NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
   ```
3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

## Tech Stack
- React 19
- Next.js 15
- Tailwind CSS

## Features
- Search UI with shimmer loading effect
- Result cards with expandable content
- Responsive and modern design

## Usage
- Enter a URL and query, then click Search.
- View results and expand to see more content.
